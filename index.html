🛡️ LinkGuard — аудит публичных ссылок на корпоративные документы

Локальный аудитор реестра ссылок для маркетинговой студии (5–30 человек). Только синтетические данные: приложение не открывает ссылки, не обращается к API и ничего никуда не отправляет — анализ выполняется в вашем браузере.

5. Ограничения и безопасность

Учебный MVP на синтетических данных. Ссылки из реестра не открываются и не проверяются, сетевых запросов нет, права доступа к реальным системам не изменяются. Обработка ошибок: неверный формат файла, отсутствие обязательных колонок и пустые значения (NaN) не приводят к сбою — выводится понятное сообщение, строка исключается из затронутых проверок с предупреждением.

Демо: нажмите «Запустить на демо-данных» — ожидается 4 нарушения. Готовый тестовый набор (10 документов, 7 нарушений: R1×2, R2×2, R3×2, R4×1) — в репозитории test_data.csv.
