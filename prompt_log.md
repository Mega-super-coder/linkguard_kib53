# Промпт-лог разработки LinkGuard

Хронология итераций с ИИ-платформой. Отклонённые варианты помечены.

## Итерация 1 — выбор стека

**Промпт:** Роль Senior Full-Stack разработчика. Нужен MVP для аудита публичных ссылок на корпоративные
документы, только синтетические данные, без сетевых запросов. Предложи простой стек.

**Варианты ИИ:**
- ✅ Python + Streamlit + Pandas — однофайловое приложение, drag-and-drop загрузка из коробки, дашборд за минимум кода. Принят.
- ❌ Flask + React — отклонён: для учебного MVP избыточен, двойная разработка фронтенда/бэкенда замедляет итерации.
- ❌ Gradio — отклонён: слабее по кастомизации таблиц и экспорту CSV.

**Причина выбора:** минимум инфраструктуры, воспроизводимость `pip install -r requirements.txt && streamlit run app.py`.

## Итерация 2 — движок правил

**Промпт:** Напиши понятный Rules Engine с 4 правилами (критический/высокий/средний риск) с рекомендациями.

**Варианты ИИ:**
- ✅ Четыре явных `if`-блока в функции `run_audit`, собирающие словари нарушений в список — читается студентом без подготовки, легко расширяется пятым правилом. Принят.
- ❌ Класс `Rule` с полиморфными `check()` — отклонён: паттерн «стратегия» усложняет чтение кода в учебном проекте.
- ❌ Декларативный YAML-конфиг правил — отклонён на этапе MVP (вынесен в план развития).

## Итерация 3 — обработка ошибок и граничные случаи

**Промпт:** Приложение не должно падать на картинке вместо CSV, на отсутствующих колонках и на NaN.
Как сделать это аккуратно?

**Варианты ИИ:**
- ✅ `try/except` вокруг чтения файла с поднятием `ValueError` с человекочитаемым сообщением; отдельный
  сворачиваемый блок предупреждений по строкам с пустыми полями. Принят.
- ❌ Молчаливый `st.stop()` — отклонён: пользователь не понимает, что пошло не так.
- ❌ Считать пустые значения нарушениями — отклонён: смешивает ошибки данных и нарушения безопасности.

**Доработка вручную:** поддержка разделителей `;` и `,` (автоопределение), `utf-8-sig` для Excel-совместимых CSV,
нормализация has_expiration («Да/Нет», True/False, 1/0).

## Итерация 4 — UI и экспорт

**Промпт:** Дашборд с метриками, фильтр по уровню риска, экспорт CSV.

**Варианты ИИ:**
- ✅ `st.metric` + `st.bar_chart` + `st.multiselect` + `st.download_button`. Принят.
- ❌ Plotly-графики — отклонён: лишняя зависимость, встроенного `st.bar_chart` достаточно для MVP.
- ❌ Кнопка «скопировать в буфер» — отклонена: `st.download_button` надёжнее работает в разных браузерах.

## Итерация 5 — тестовые данные

**Промпт:** Составь синтетический test_data.csv: несколько безопасных документов и по одному срабатыванию
на каждое правило.

Составлено 10 строк: 3 безопасные, срабатывания R1 (2 строки, включая «Строго конфиденциальный»),
R2 (2 строки), R3 (2 строки), R4. Проверено: движок выдаёт ожидаемые 7 нарушений.
